# 간편 QR 계좌송금 MVP

행사장에서 판매자가 받을 사람과 금액만 선택해 QR을 보여주는 정적 웹앱입니다. 고객은 QR을 촬영하고 계좌번호를 복사한 뒤 자신이 사용하는 은행 앱에서 금액을 직접 입력합니다.

이 앱은 결제대행 서비스가 아니며 송금이나 입금을 자동 처리하지 않습니다. 판매자는 은행 문자 또는 앱 알림으로 실제 입금을 확인해야 합니다.

## 1차 MVP 기능

- 사용자 1·사용자 2 계좌 선택 및 휴대폰별 선택 기억
- 최종 결제 금액 직접 입력
- 계좌정보가 포함되지 않은 짧은 QR 주소 생성
- 고객 화면의 금액·은행·예금주·계좌번호 표시
- 계좌번호 복사
- 입금 확인 후 기기별 판매 건수·합계·내역 저장

상품, 토스 자동 입력, 은행 앱 실행, 서버, 로그인, 기기간 기록 동기화는 포함하지 않습니다.

## 로컬 실행

Node.js 22 이상에서 실행합니다.

가장 쉬운 방법은 프로젝트 폴더의 `run-dev.cmd`를 더블클릭하는 것입니다. 어느 폴더에서 실행해도 스크립트가 자동으로 프로젝트 폴더로 이동하고, 최초 실행이면 필요한 패키지를 설치합니다.

PowerShell에서 직접 실행할 때는 먼저 프로젝트 폴더로 이동해야 합니다. 명령 끝에 `\`를 붙이지 마세요.

```powershell
Set-Location -LiteralPath 'C:\QR-pay service'
npm.cmd install
npm.cmd run dev
```

개발 화면은 `.env.development`의 가짜 계좌를 사용합니다. 실제 송금에 사용하지 마세요.

전체 검증:

```powershell
npm.cmd run test:run
npm.cmd run build
```

## GitHub Pages 배포

### 1. 공개 저장소 만들기

GitHub 무료 계정의 Pages를 사용하려면 공개 저장소가 필요합니다. 이 폴더를 새 저장소의 `main` 브랜치에 올립니다. 실제 계좌번호는 파일에 적거나 커밋하지 않습니다.

### 2. 저장소 변수 등록

GitHub 저장소의 `Settings → Secrets and variables → Actions → Variables`에 다음 값을 등록합니다.

| 이름 | 예시 |
|---|---|
| `QR_PAY_SHOP_NAME` | 행사 판매점 |
| `QR_PAY_USER1_LABEL` | 사용자 1 또는 알아보기 쉬운 호칭 |
| `QR_PAY_USER1_COLOR` | `#155E75` |
| `QR_PAY_USER1_BANK` | 실제 은행명 |
| `QR_PAY_USER2_LABEL` | 사용자 2 또는 알아보기 쉬운 호칭 |
| `QR_PAY_USER2_COLOR` | `#9A3412` |
| `QR_PAY_USER2_BANK` | 실제 은행명 |

두 색은 서로 달라야 합니다.

### 3. 저장소 비밀값 등록

같은 화면의 `Secrets`에 다음 값을 등록합니다.

| 이름 | 값 |
|---|---|
| `QR_PAY_USER1_HOLDER` | 사용자 1의 실제 예금주 |
| `QR_PAY_USER1_ACCOUNT` | 사용자 1의 실제 계좌번호 |
| `QR_PAY_USER2_HOLDER` | 사용자 2의 실제 예금주 |
| `QR_PAY_USER2_ACCOUNT` | 사용자 2의 실제 계좌번호 |

계좌번호에는 숫자, 공백, 하이픈만 사용할 수 있습니다. Secret에 저장해도 배포된 고객 페이지에는 송금을 위해 계좌정보가 표시되므로 완전한 비밀정보가 되지는 않습니다. Secret을 쓰는 목적은 공개 Git 기록과 저장소 검색에 계좌가 남지 않게 하는 것입니다.

### 4. Pages 켜기

`Settings → Pages → Build and deployment → Source`에서 `GitHub Actions`를 선택합니다. `main` 브랜치에 올릴 때 테스트와 빌드를 통과하면 자동 배포됩니다.

## 두 분 휴대폰에 설치

1. 배포된 GitHub Pages 주소를 휴대폰 브라우저로 엽니다.
2. 장인어른 휴대폰에서는 사용자 1, 장모님 휴대폰에서는 사용자 2를 한 번 선택합니다.
3. 브라우저 메뉴에서 `홈 화면에 추가`를 선택합니다.
4. 각 휴대폰에서 100원을 입력해 QR을 만듭니다.
5. 다른 휴대폰 카메라로 QR을 찍어 은행·예금주·계좌가 정확한지 확인합니다.
6. 실제로 100원을 송금하고 올바른 휴대폰에 입금 알림이 오는지 확인합니다.

## 행사 전 필수 점검

- 두 사용자 모두 100원 테스트 송금 성공
- 사용자별 은행·예금주·계좌번호 일치
- 고객 화면에서 계좌번호 복사 성공
- 고객 은행 앱에서 계좌 붙여넣기와 금액 직접 입력 성공
- 판매자 휴대폰에서 입금 문자 또는 앱 알림 확인
- `입금 확인 후 다음 손님`을 누른 뒤 기록 화면의 건수·합계 증가

입금 알림을 확인하기 전에는 상품을 건네지 마세요.
