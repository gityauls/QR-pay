# QR 송금 처음 실행하기

이 안내는 GitHub를 모르는 사용자도 같은 QR 송금 앱 주소를 휴대폰에 설치하고 자기 계좌를 등록할 수 있도록 작성했습니다.

중요: QR을 만들었다고 입금이 끝난 것은 아닙니다. 실제 입금은 은행 문자나 은행 앱 알림으로 확인하세요.

## 1. 배포 주소 열기

휴대폰의 Chrome, 삼성 인터넷 또는 Safari에서 아래 주소를 엽니다.

`https://gityauls.github.io/QR-pay/`

처음 열면 `처음 설정` 화면이 표시됩니다.

## 2. 판매점과 첫 계좌 등록

다음 값을 입력합니다.

1. 판매점 이름
2. 받는 분 표시 이름
3. 은행 선택
4. 예금주 이름
5. 계좌번호
6. `저장하고 시작하기`

은행이 목록에 없으면 `목록에 없는 은행`에 통장에 적힌 이름을 입력하세요. 계좌번호에는 숫자, 공백, 하이픈을 사용할 수 있습니다. 받는 분의 색상은 앱이 자동으로 정합니다.

입력한 정보는 현재 휴대폰 브라우저에만 저장됩니다. GitHub나 별도 서버로 전송되지 않습니다. 브라우저 데이터 또는 설치한 앱 데이터를 삭제하면 다시 입력해야 합니다.

## 3. 홈 화면에 설치

설정 저장 뒤 설치 안내가 표시됩니다.

### 삼성 인터넷

1. 메뉴 `≡` 또는 `⋮`
2. `현재 페이지 추가`
3. `홈 화면`

### Android Chrome

1. 메뉴 `⋮`
2. `앱 설치` 또는 `홈 화면에 추가`

### iPhone Safari

1. 아래쪽 공유 버튼
2. `홈 화면에 추가`
3. 오른쪽 위 `추가`

설치하지 않아도 브라우저에서 사용할 수 있습니다.

## 4. 받는 분 추가·수정·삭제

금액 입력 화면 오른쪽 위 `설정`을 누릅니다.

- `+ 받는 분 추가`: 계좌를 추가합니다.
- 각 받는 분의 `수정`: 이름·은행·예금주·계좌번호를 바꿉니다.
- `삭제`: 확인 후 해당 받는 분을 지웁니다.
- `판매점 이름 수정`: 화면에 표시되는 상호를 바꿉니다.
- `받는 분 바꾸기`: 현재 QR을 받을 사람을 선택합니다.

마지막 한 명은 삭제할 수 없습니다. 다른 받는 분을 먼저 추가하세요. 같은 계좌번호는 중복 등록할 수 없습니다.

## 5. 행사장에서 사용

1. 화면 위의 받는 분·은행·계좌번호를 확인합니다.
2. `+1만원`, `+5천원`, `+1천원` 또는 숫자판으로 금액을 입력합니다.
3. 금액과 한글 금액이 맞는지 확인합니다.
4. `QR 만들기`를 누릅니다.
5. 고객에게 QR을 보여 줍니다.
6. 고객은 카메라로 QR을 찍고 은행·예금주·계좌번호·금액을 확인합니다.
7. 고객이 은행 앱 또는 토스로 송금합니다.
8. 판매자는 은행 알림으로 실제 입금을 확인합니다.

QR 화면은 15초 뒤 금액 입력 화면으로 돌아갑니다. `설정`에서는 오늘 만든 QR 건수와 합계를 볼 수 있습니다. 이 합계는 실제 입금 확인 결과가 아니라 QR 생성 기록입니다.

## 6. 행사 전 시험

등록한 받는 분마다 1,000원 시험 송금을 합니다.

1. 1,000원 QR을 만듭니다.
2. 다른 휴대폰으로 QR을 찍습니다.
3. 은행·예금주·전체 계좌번호·1,000원이 모두 맞는지 확인합니다.
4. 토스와 자주 사용하는 은행 버튼을 각각 확인합니다.
5. 실제로 1,000원을 송금하고 입금 알림을 확인합니다.

하나라도 다르면 행사에서 사용하지 말고 설정의 계좌 정보를 다시 확인하세요.

## 7. 개발자용 배포

계좌용 GitHub Variables와 Secrets는 더 이상 필요하지 않습니다.

1. 저장소 `Settings → Pages`
2. `Build and deployment`의 `Source`를 `GitHub Actions`로 선택
3. `Actions → Test and deploy QR Pay`에서 초록색 체크 확인
4. `https://gityauls.github.io/QR-pay/` 열기

코드를 `main`에 올리면 자동으로 다시 배포됩니다.

## 8. 문제가 있을 때

- 화면이 예전 모습이면 앱을 완전히 닫았다가 다시 열고 새로고침합니다.
- 설정이 사라졌다면 브라우저 데이터가 삭제된 것입니다. 계좌를 다시 등록합니다.
- 아이폰의 일반 은행 버튼은 계좌번호를 복사한 뒤 은행 앱을 직접 열도록 안내합니다.
- 토스가 열리지 않으면 계좌번호를 복사해 토스를 직접 열고 송금합니다.
- QR 주소가 `localhost`라면 다른 휴대폰에서 열리지 않습니다. GitHub Pages 주소를 사용하세요.
