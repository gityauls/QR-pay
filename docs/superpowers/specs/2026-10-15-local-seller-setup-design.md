# 로컬 판매자 설정 및 한 화면 금액 입력 설계

## 목표

공용 GitHub Pages 앱에서 판매점과 여러 받는 분을 휴대폰에만 저장하고, 고객 QR에는 송금에 필요한 정보를 URL fragment로 전달한다. 금액 입력은 승인된 B안 비율로 줄여 360×640px 이상의 일반 세로 화면에서 `QR 만들기`까지 보이게 한다.

## 핵심 설계

- 첫 실행에 판매점 이름, 표시 이름, 은행, 예금주, 계좌번호를 입력한다.
- 주요 은행 선택과 기타 직접 입력을 제공하고 색상은 자동 배정한다.
- 설정에서 판매점 이름과 받는 분을 추가·수정·삭제한다. 마지막 받는 분 삭제와 중복 계좌는 차단한다.
- 설정과 매출은 현재 휴대폰의 `localStorage`에만 저장한다.
- 고객 URL은 `/pay/#<base64url payload>`이며 fragment는 서버에 전송되지 않지만 암호화는 아니다.
- 실제 계좌 환경변수 의존성을 제거하고 새 브라우저는 빈 초기 설정부터 시작한다.
- 저장, 관리, QR payload, 고객 화면, 전체 빌드 및 360×640/390×844 화면을 검증한다.
