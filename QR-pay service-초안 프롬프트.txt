🛠️ 개발 구현 원리 (어떻게 작동하나요?)

보안 규정상 일반 개인 개발자가 타인의 은행 앱을 직접 원격 제어하여 금액을 강제로 입력하는 API는 사용할 수 없습니다. 따라서 상용 서비스들은 웹 브라우저의 '클립보드(복사) 기능'과 은행별 앱을 깨우는 '딥링크(Deep Link)' 기술을 조합하여 구현합니다.
1. 정보를 담은 고유 URL 생성:
은행코드, 계좌번호, 예금주, 금액 정보를 특정 규격의 파라미터(예: ?bank=011&account=1234&amount=10000)로 정의하고, 이를 처리할 수 있는 본인의 웹페이지 주소(URL)를 만듭니다.
2. URL을 QR 코드로 변환:
개발 언어(Python, JavaScript 등)의 오픈소스 라이브러리를 사용해 이 URL이 담긴 QR 코드 이미지를 생성합니다.
3. 웹페이지 내 자동화 로직 구현:
사용자가 QR을 찍어 해당 웹페이지에 접속하면 다음과 같은 자바스크립트(JavaScript) 코드가 순차적으로 실행됩니다.
	• 금액 및 계좌 자동 복사: 페이지가 열리자마자 브라우저의 클립보드에 계좌번호와 금액 데이터가 복사됩니다.
	• 은행 앱 전환 (App Scheme 이용): 사용자가 화면에서 시중은행 버튼을 누르면, 각 은행 앱의 고유 호출 주소(예: 국민은행 kb-bank://, 신한은행 shinhan-srbbank://)를 실행시켜 앱을 띄웁니다.
	• 자동 입력 유도: 은행 앱이 켜지면서 "클립보드 읽기 허용" 팝업이 뜨고, 사용자가 허용하면 이체 화면에 계좌와 금액이 자동으로 붙여넣어집니다.

💻 간단한 구현 예시 코드 (Python & Node.js 활용)


1) 백엔드: 정보가 담긴 URL을 QR 코드로 만들기 (Python 예시)

qrcode 라이브러리를 사용하면 계좌 정보와 금액이 포함된 웹페이지 주소를 순식간에 QR 이미지로 바꿀 수 있습니다.
python
import qrcode

# 내가 만든 중계 웹페이지 주소에 계좌번호와 금액 매개변수 추가
# (011 = 농협코드, 10000 = 만 원)
payment_url = "https://my-qr-service.com"

# QR 코드 생성
qr = qrcode.QRCode(version=1, box_size=10, border=4)
qr.add_data(payment_url)
qr.make(fit=True)

# 이미지로 저장
img = qr.make_image(fill_color="black", back_color="white")
img.save("money_transfer_qr.png")
코드를 사용할 때는 주의가 필요합니다.

2) 프론트엔드: 스캔 시 클립보드 복사 및 은행 앱 띄우기 (JavaScript 예시)

사용자가 카메라로 스캔하여 접속했을 때, 화면에 뜨는 페이지의 핵심 코드입니다.
javascript
// 1. URL에서 계좌와 금액 파라미터 읽어오기
const urlParams = new URLSearchParams(window.location.search);
const accountNum = urlParams.get('account');
const amount = urlParams.get('amount');

// 2. 사용자가 스캔 후 화면을 누르면 계좌번호와 금액을 자동으로 복사
function copyToClipboard() {
    const transferText = `${accountNum} ${amount}원`; // 은행 앱 인식을 위한 텍스트 구조화
    navigator.clipboard.writeText(transferText).then(() => {
        alert("계좌번호와 금액이 복사되었습니다! 은행 앱으로 이동합니다.");

        // 3. 토스 앱이나 카카오뱅크 앱 등을 강제로 열기 (딥링크 스키마 사용)
        window.location.href = "toss://"; // 혹은 "kakaobank://" 등 은행별 스키마 입력
    });
}
코드를 사용할 때는 주의가 필요합니다.
